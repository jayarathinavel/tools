***Tools:***

This app is a web application that provides various tools and features for managing expenses, tracking vehicles, and managing bill splits for a group of people or an individual. The app is built using the PHP, HTML, CSS, and JavaScript programming languages. Uses MySQL as the database, Bootstrap as the front-end framework. More features to be added.
